# 본문 파일을 두는 자리

이 폴더는 비어 있는 게 정상입니다.

앱의 `본문` 화면에서 성경을 붙여넣어 가져온 뒤, `파일로` 버튼을 누르면
`GEN.js` 같은 파일을 내려받습니다. 그 파일을 이 폴더에 두면 다음부터
앱이 열릴 때 알아서 읽어 들입니다. 브라우저 저장소가 비워져도 복구됩니다.

책을 여럿 두었다면 `목록 파일(index.js) 내보내기`로 받은 `index.js`도 함께 두세요.

```
data/bible/
  index.js     ← 어떤 책이 있는지 목록
  GEN.js       ← 창세기 본문
  JHN.js       ← 요한복음 본문
```

## 커밋하지 마세요

번역본 본문은 저작권물입니다. 개인적으로 쓰는 것과 공개 저장소에 올리는 것은
다릅니다. `.gitignore`가 `data/bible/*.js`를 막고 있으니 억지로 풀지 마세요.
